## 一句话结论

对 **205 个损坏容器 / 42.63 GB** 做双分支切出，
得到 **16,974 个唯一媒体对象**，其中 **15,449 个可解码**、
**13,212 个非退化**、**1,352 个达到高清标准**（`min(w,h) ≥ 600`）。

在 46,185 条参考指纹、汉明距离 ≤16 的判定下，
仅 **3 个**高清对象"未找到候选"。按采样外推，
整批 42.63 GB 中**可能**存在的唯一内容约占 **0.5%–0.7%**。

**这个数字的意义是：99% 以上的尾部数据在指定参考池内都能找到对应，
因此不具备"独有照片"的价值。但它同样不能证明可以删除。**

---

## 三个必须强调的边界

1. **"未找到候选" ≠ "独有照片" ≠ "可删除"**
   正确表述：*在指定参考池和阈值内未找到候选*。

2. **感知哈希不是证据，只是候选生成器**
   实测：距离 5 以上的匹配，误报率 **100%**（见 04 篇）。

3. **7 个缺陷都是"静默失败"**
   不报错、不中断、结果是合法但错误的数字。
   这是本项目最重要的工程教训（见 03 篇）。
