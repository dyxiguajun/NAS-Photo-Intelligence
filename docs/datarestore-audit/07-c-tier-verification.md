# 07 C 层对象的像素级验证

## 7.1 什么是 C 层

C 层 = **pHash 距离 > 16，在参考池内未找到候选**的对象。

| 统计口径 | 数量 |
|---|---:|
| C 层总数（全部尺寸） | 52 |
| 其中高清且非退化 | **3** |

本文验证的是那 **3 个高清对象**——它们是整批 42.63 GB 中
唯一"可能具有独立价值"的部分。

## 7.2 验证方法

| 项 | 设定 |
|---|---|
| 参考池 | 160,506 条 pHash（其中短边 ≥600 的 40,676 条） |
| 候选规则 | 短边 ≥600 且 pHash 距离 ≤20 |
| 每对象候选数 | 5（取距离最近者） |
| 真值判据 | 多尺度 NCC，任一尺度 ≥ 0.90 视为同内容 |
| 尺度 | 16 / 32 / 64 / 128 px 灰度 |

## 7.3 结果

| 对象 | 最近候选距离 | **最高 NCC** | 判定 |
|---|---:|---:|---|
| 769×631 | 18 | **0.3834** | 不同内容 |
| 1000×1000 | 18 | **0.4948** | 不同内容 |
| 1920×620 | 18 | **0.3863** | 不同内容 |

**三个对象的最高 NCC 全部 < 0.50，远低于 0.90 阈值。**

### 一个值得注意的现象：距离下限

每个对象在 `d=18` 上各有 **130–172 个**大尺寸候选并列。
这不是"找到了很多相似图"，而是**距离下限**——
说明这些图像的 pHash 与自然照片群体普遍相距 ~18 位。
这是低信息量或结构特异图像的典型特征。

## 7.4 形态特征刻画

视觉引擎不可用，因此改用可量化指标：

| 对象 | 颜色数 | 饱和度 | 边缘密度 | 平坦区占比 | 直方图熵 | 灰度 std |
|---|---:|---:|---:|---:|---:|---:|
| 769×631 | 11,857 | 23.2 | 4.61 | **43.4%** | 4.94 | 33.2 |
| **1000×1000** | **210,074** | 32.1 | 3.70 | 20.1% | **7.79** | **78.6** |
| 1920×620 | 59,439 | 20.4 | **2.14** | 2.5% | 6.59 | 33.1 |
| *对照（真实照片）* | *186,213* | *42.0* | *4.00* | *1.8%* | *7.21* | *50.0* |

### 解读

| 对象 | 形态判断 | 依据 |
|---|---|---|
| 769×631 | **图形 / 截图** | 43.4% 平坦区、颜色数仅 1.2 万、熵 4.94 |
| **1000×1000** | **真实照片内容** | 颜色数 21 万、熵 7.79（**高于**对照照片 7.21）、std 78.6 |
| 1920×620 | 宽幅横幅 / 拼接 | 边缘密度仅 2.14（最低）、熵 6.59、超宽比例 |

**1000×1000 是唯一值得人工复核的对象**：
它的信息量指标强于一张已知的真实照片。

## 7.5 结论

1. **C 层分类是正确的**：3 个对象的最高 NCC 均 < 0.50，
   证实参考池内确实没有同内容候选。

2. **其中 2 个很可能不是普通照片**（图形/截图/横幅），
   即便"唯一"也不具备照片价值。

3. **1 个（1000×1000）具有真实照片特征**，
   建议人工目视确认后再定性。

4. 按措辞纪律，正确表述为：
   > 在指定参考池（160,506 条 pHash，其中大尺寸 40,676）与阈值内未找到候选

   **不称"独有照片"，不作删除依据。**

## 7.6 局限

- 视觉引擎不可用，**未做人工目视**，形态判断基于量化特征
- 每对象仅取 5 个最近候选，未穷举 130+ 个候选
- 未对 49 个非高清 C 层对象做验证（它们尺寸太小，价值有限）

## 7.7 复现

```bash
# 1) 用 pHash 找候选（短边>=600 且 d<=20）
python3 dsh/c_tier_verify.py --list-candidates

# 2) 取回候选文件后做多尺度 NCC
python3 dsh/c_tier_verify.py --ncc

# 3) 形态特征
python3 dsh/c_tier_verify.py --features
```
