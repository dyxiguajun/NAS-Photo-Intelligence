这个页面是什么

本页是静态的「文件目录 + 纯文本直链」索引，帮助外部 AI 在不登录 GitHub 的情况下定位本项目的关键源码、架构说明与测试。页面本身不包含任何照片、数据库、索引或凭据；所有链接只指向已进入版本控制且经过脱敏检查的文件。

本页不替代仓库内的权威文档：docs/AI_REVIEW.md 是项目维护的外部审查入口，README.md 说明运行方式。运行时权威状态保存在本地 reports/agent-coordination/STATE.json，该目录按设计不进入 Git。

4. 架构说明（阅读导引）

  • 只读优先：NAS 只提供原始文件；程序只写本地 SQLite、日志和报告。不删除、不移动、不改名、不写回 EXIF。
  • 三层证据：L0 = 完整 SHA-256 字节重复；L1 = 指定解码器/规范化版本下完整 RGBA8 像素相同；L2 = pHash/dHash 视觉候选，仅作关联建议，不能作为删除依据。
  • 显式范围：scan / hash / 视觉任务都必须提供 manifest，不自动全库扫描；读取字节预算跨 resume 累计，不因重启重置。
  • 可恢复队列：SQLite WAL + 每文件事务 + 独立 worker 进程组；running 条目在 resume 时重置，已提交结果不重做。
  • 隔离：单图独立进程解码，像素门限、RSS 采样与超时保护；Czkawka 只读扫描使用固定摘要 Docker 镜像。
  • 身份模型：source_id + relative_path 为稳定逻辑身份；mount_root 只是可变挂载入口。
  • 完整设计见 docs/ARCHITECTURE.md。

6. 匿名访问实测与已知限制

2026-11-11（America/Los_Angeles）使用不带任何凭证的请求实测：github.com 普通文件页、raw.githubusercontent.com、GitHub API、jsDelivr 镜像均为 HTTP 200；不存在的路径为 HTTP 404（表示未发布，不是 401/403 权限拒绝）。完整逐条记录见 ACCESS_REPORT.md。

重要限制（不是仓库权限问题）

实测中 curl、浏览器、ChatGPT-User、GPTBot、OAI-SearchBot、Claude-User、ClaudeBot 等 UA 对 github.com 的服务端响应全部为 HTTP 200，GitHub 并未按 UA 在 HTTP 层拦截。但 github.com/robots.txt 针对这些 AI UA 明确包含 Disallow: /*/tree/、Disallow: /*/raw/、Disallow: /*/blame/ 等规则。遵守 robots.txt 的 ChatGPT / Claude 网页抓取工具可能因此拒绝打开 github.com 的目录页与 /raw/ 页面，即便链接本身返回 200。

规避方式是本页统一使用 raw.githubusercontent.com 纯文本直链（该域无 robots.txt）或本 Pages 站点。更改 GitHub 仓库权限、可见性或分支保护都不能解决抓取端的 robots 策略；若某个特定网页工具仍被阻止，应记录为工具侧限制，而不是声称权限调整可以修复。

另：匿名 GitHub API 限额为 60 次/小时，大量读取可能返回 403（限流），同样不是权限问题。
