# 02 损坏容器双分支切出结论

## 2.1 问题的本质

这 205 个容器**不是"损坏的 PNG"**，而是：
**一个合法的图片文件 + 尾部附加数据（未分类）**。

`3A212378.png` 的典型结构：

```
offset 0            : 合法 PNG（929×1365，24 个 chunk，286,440 字节）
offset 286,440 之后 : 1.5 GB 未分类数据
```

尾部数据里混着**完整的 JPEG 和 PNG 流**。只按 PNG 签名扫会漏掉全部 JPEG。

## 2.2 双分支切出

| 项 | PNG 分支 | JPEG 分支 | 合计 |
|---|---:|---:|---:|
| 签名命中 | 47,519 | 20,441 | 67,960 |
| 完整流（找到结束标记） | 45,363 | 14,301 | 59,664 |
| 切出对象 | 12,080 | 13,865 | 25,945 |
| 去重后唯一 | 8,836 | 8,138 | **16,974** |
| 可解码 | 8,836 | 6,613 | **15,449** |
| 非退化 | 6,644 | 6,568 | **13,212** |
| **高清 `min≥600`** | **962** | **390** | **1,352** |

### 结构恒等式校验（全部通过）

```
PNG :  45,363 完整流 + 2,156 损坏流 = 47,519 签名命中   ✓
PNG :  12,080 导出   + 33,283 跳过   = 45,363 完整流   ✓
PNG :   8,836 唯一   +  3,244 折叠   = 12,080 导出     ✓
```

## 2.3 尺寸分层

| 档 | PNG | JPEG | 合计 |
|---|---:|---:|---:|
| `<128px` | 1,040 | 4,445 | 5,485 |
| 128–255 | 2,634 | 912 | 3,546 |
| 256–599 | 2,008 | 821 | 2,829 |
| **`≥600px`** | **962** | **390** | **1,352** |

JPEG 分支 67% 是 `<128px` 缩略图碎片（`80×60`、`86×60` 一类）。
**但不能因为"多数是碎片"就忽略分支**——高清部分贡献了 390 个真实对象。

## 2.4 置信分层（仅高清 1,352 个）

| 层 | 判据 | PNG | JPEG | 合计 |
|---|---|---:|---:|---:|
| A_identical | pHash 距离 = 0 | 183 | 13 | 196 |
| A_near | 距离 1–8 | 28 | 8 | 36 |
| B_weak | 距离 9–16 | 749 | 368 | 1,117 |
| **C_no_ref** | **距离 > 16** | **2** | **1** | **3** |

参考池：46,185 条 pHash。

## 2.5 C 层完整清单（3 个对象）

| 分支 | 尺寸 | 最近距离 | 对象 SHA-256（前 16 位） |
|---|---:|---:|---|
| PNG | 769×631 | 18 | `c37c02b6f5bb7f81` |
| PNG | 1000×1000 | 18 | `2cca604e551bec60` |
| JPEG | 1920×620 | 18 | `f39e7d17b776400f` |

### 措辞纪律（硬性）

正确表述：

> **在指定参考池（46,185 条 pHash）和阈值（汉明距离 ≤16）内未找到候选**

禁止表述：
- ❌ "独有照片"
- ❌ "已证明无对应"
- ❌ "可安全删除"
- ❌ "垃圾数据"

原因见 [04-matching-metrics.md](04-matching-metrics.md)：
距离 9–16 区间的误报率是 100%，距离 >16 只能说明"没有近似候选"，
不能说明"没有同一个原始事件的其它版本"（可能只是曝光/裁剪差异更大）。

## 2.6 高清对象的真实尺寸样本

JPEG 分支高清对象中确认存在的分辨率：

```
4096×2304   3841×2400   3840×2160   3344×1080   2048×2048   1920×1080
```

这些**不是缩略图**，是真实的高分辨率照片内容。

## 2.7 唯一性结论

| 口径 | 数值 |
|---|---:|
| 损坏容器总体积 | 42.63 GB |
| 高清非退化对象 | 1,352 |
| 其中无候选 | 3 |
| 采样外推"可能唯一"占比 | **0.5%–0.7%** |

**这是一个采样外推，不是逐像素全验。**
严格表述应为：按 111 个分层抽样对象的多尺度归一化互相关（NCC）验证，
约 62% 的样本在高清层无法与参考池对齐到 NCC ≥ 0.90；
但该比例不能直接当作全量结论。

## 2.8 可复现命令

```bash
# 1) 有界格式核验：确定哪些容器含 JPEG/PNG 流
python3 dsh/verify_sigs.py <容器清单> out.jsonl

# 2) JPEG 切出（连续扫描 + 结构合法性 + 解码验证）
python3 dsh/jpeg_carve.py <容器清单> <隔离输出目录>/

# 3) PNG 切出
python3 dsh/png_carve.py  <容器清单> <隔离输出目录>/

# 4) 双分支合并去重 + 分层
python dsh/carve_merge.py <png目录> <png清单> <jpeg目录> <jpeg清单> out.json
```
